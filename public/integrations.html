MCP first

If it speaks MCP, it belongs.

Mycelium uses MCP to connect tools, resources, and prompts. Point it at a local server, a hosted endpoint, or your own internal service. Scope access per agent and keep the credentials in the workspace boundary.

# example
mycelium mcp add internal-crm \
  --url https://mcp.internal.example/sse \
  --scope crm.read
