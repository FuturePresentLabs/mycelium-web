Legal

Data processing addendum.

For enterprise customers who need a defined data boundary, subprocessor review, and a signed DPA before deployment.

Status

The launch site publishes this summary as a placeholder. A counsel-reviewed DPA is available on request for Enterprise customers.

Scope

The DPA will cover the hosted Mycelium service, the categories of personal data processed, the purpose of processing, retention, security measures, subprocessors, and the customer's instructions.

Data location

Hosted workspaces run on FPL Cloud infrastructure. Enterprise customers can request a dedicated deployment and a specific data boundary.

Subprocessors

Current infrastructure and payment providers include Cloudflare and Stripe. The signed DPA will list the current subprocessors and the notice period for changes.

Request a copy

Email legal@fpl.dev with the subject “Mycelium DPA”.
