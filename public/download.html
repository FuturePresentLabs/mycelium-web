Self-host

Run it yourself. Keep the keys.

Mycelium is open source. Install it on a laptop, a server, or your own cloud. There is no license key, no phone-home requirement, and no feature held back for the hosted plan.

Read the install guide →View the repository

Fast path

One command.

The installer builds the core binaries, enrolls the host, and prompts for the optional pieces. It is safe to re-run.

bash
$ curl --proto '=https' --tlsv1.2 -fsS \
  https://raw.githubusercontent.com/mycelium-linux/mycelium/master/install.sh | bash
curl --proto '=https' --tlsv1.2 -fsS https://raw.githubusercontent.com/mycelium-linux/mycelium/master/install.sh | bash

What you need

A machine and a little patience.

  • macOS or a systemd-based Linux distribution
  • 4 vCPU, 8 GB RAM, 100 GB free disk for a comfortable server
  • A domain name if you want remote access and TLS
  • Optional: a model provider key, or a local OpenAI-compatible endpoint
  • Optional: object storage for larger file workspaces

For production, use the server guide. It covers TLS, reverse proxy, backups, and upgrades.
